## 🛠️ Featured Projects

### 🏛️ SmartHeritage
A full-stack heritage platform with streaming AI chat and site content in **English, Telugu, and Hindi**.
- React.js frontend, Node.js/Express + MongoDB backend, and a Python GenAI microservice (FastAPI, LangGraph, Groq)
- **Self-correcting generation loop**: JSON parsing, schema validation, and feedback-driven regeneration (up to 3 retries) that returns the best-scoring attempt
- **Observability**: every graph node and LLM call traced in LangSmith, tagged by site, language, and section
- **Evaluation framework**: deterministic checks plus LLM-as-judge rubrics (factual accuracy, consistency, completeness, tone), with offline LangSmith experiments to compare prompts and models

`React` `Node.js` `MongoDB` `FastAPI` `LangGraph` `LangSmith` `Groq`  
🔗 [Repo](https://github.com/kalyan021004/SmartHeritage) • [Live](https://gen-ai-project-h3hs.vercel.app/)

### 🛡️ Digital Arrest Scam Shield
A real-time system that flags "digital arrest" scam calls during live transcription.
- Embeddings and **ChromaDB** vector search over a corpus of documented scam patterns
- **5-node LangGraph pipeline** (filtering, retrieval, risk correlation, decision routing, alerting) over a typed shared-state schema, escalating by risk level
- Exposed through **MCP tools** and **FastAPI** REST endpoints, and containerized with **Docker**

`Python` `LangGraph` `RAG` `ChromaDB` `MCP` `FastAPI` `NetworkX` `Docker`  
🔗 [Repo](https://github.com/kalyan021004/Digital-crime-arrest)

### 🏘️ DigitalConnect
A rural governance platform connecting citizens, Gram Panchayat officials, and healthcare providers.
- Role-specific dashboards that digitize services which previously required in-person visits
- Government-scheme workflow: eligibility check, document upload, and application tracking through to approval
- Grievance filing and health-appointment booking, secured with **JWT/bcrypt** authentication and role-based access control across 3 user roles

`Node.js` `Express` `MongoDB` `React` `REST APIs`  
🔗 [Repo](https://github.com/kalyan021004/DigitalConnect) • [Live](https://rural-connect-smoky.vercel.app/)
